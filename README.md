# Anor Balance

Неофициальное Android-приложение для просмотра баланса и остатков Anor. Личный учебный проект; возможно распространение подписанного APK среди друзей. Каждый экземпляр работает независимо, с данными владельца телефона. Сервер, аккаунты, синхронизация и аналитика не нужны.

## Состояние на 10 ноября 2026

Подготовлены только требования, архитектура и план. Код приложения отсутствует, зависимости не устанавливались. На момент осмотра каталог не содержал исходников и рабочего Git-репозитория (`git status` завершился сообщением `not a git repository`); служебные каталоги среды не изменялись.

**Реализация начинается только после следующего разрешения владельца.** Ни USSD на устройстве, ни формат SMS ещё не проверены.

## Предлагаемое решение

React Native + TypeScript, Expo Development Build/Prebuild, локальный Expo-модуль на Kotlin, Zustand, AsyncStorage и обычный React Native StyleSheet. Выбор версий SDK и минимальной версии Android — после получения модели телефона и проверки совместимости. Expo Go не подходит для собственной нативной интеграции.

Dashboard показывает последние известные данные, источник и время получения каждого показателя. Денежный баланс предполагается получать через `*100#`; для пакетов MVP предусматривает вставку SMS и предварительный просмотр результата. Неизвестное значение отображается как «Нет данных», а не 0. Выбранный вручную тариф не является подтверждением тарифа оператора.

## Что нужно до интеграций

Уже получены: A12, Android 12, две SIM, Anor основная в слоте 2; USSD-образец `Тавозуни Шумо: 0.05TJS.` и SMS пакетов ULTRA. Владелец подтвердил раздельные каналы: баланс через USSD, пакеты через SMS. Образцы описаны в DATA_MODELS, production-парсер ещё не создан. Осталось уточнить точный model code/One UI, sender/время SMS, смысл основного интернет-поля и проверить native callback на телефоне. Полный номер телефона и IMEI не нужны. Подробная матрица проверок — в Android-документе.

## Сборка в дальнейшем

После разрешения сначала зафиксировать совместимые версии и окружение. Разработка — локальный development build, доставка — подписанный release APK со встроенным JS, работающий без Metro. EAS Cloud не обязателен. Ключ подписи хранится отдельно от репозитория; обновления друзьям подписываются тем же ключом. Сейчас команд установки/запуска нет: приложения ещё нет.

## Окружение

Уже найдены Git, Node.js и npm. Выбран путь сборки без обязательной Android Studio/эмулятора: совместимый JDK и Android SDK CLI + adb. Установленная Java 25 ещё не подтверждена как подходящий JDK; SDK/adb не найдены в стандартных путях. Полный порядок настройки после разрешения — в ANDROID_INTEGRATION. Ничего не устанавливалось.
